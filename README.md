# GYM Management System

## Technologies
- HTML, CSS, JavaScript
- Firebase (Authentication & Firestore)

## Description
A web-based system to manage gym operations including members, payments, notifications, and reports. Eliminates paper receipts and digitizes gym management.

## Modules
- **Admin:** Add/update/delete members, create bills, send notifications, export reports.
- **Member:** View bills, receive notifications.
- **User:** Search member records, view member details.

## Features
- Modular and maintainable code
- Firebase integration
- Logging for all actions
- Cloud or local deployment ready
- Optimized and testable

## Setup
1. Clone the repo
2. Add your Firebase config in `js/firebase-config.js`
3. Open `index.html` in browser
4. Login with admin, member, or user credentials
